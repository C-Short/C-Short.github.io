Chicago Transit & Grocery Access

How far can you actually walk from an L station before you reach a grocery store? This project computes real network walksheds — not straight-line buffers — around every CTA L station citywide, and overlays them against walkable grocery access to show where the two genuinely coincide.

Methods

Station locations come from the Chicago Data Portal; grocery and supermarket locations from OpenStreetMap, queried within a 1.5 mile buffer of the transit network. Walksheds are computed on the actual OSM pedestrian graph using multi-source Dijkstra search from every station (or store) simultaneously, then rendered by buffering the reachable street edges and intersections — so the shape follows real sidewalks and blocks rather than an idealized circle.

The map itself computes transit–grocery overlap live in the browser using Turf.js, so the two accessibility layers stay perfectly aligned no matter which distance thresholds you choose.
